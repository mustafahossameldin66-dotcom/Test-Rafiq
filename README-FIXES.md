# Rafiq Experience — Content & UX Fixes

## الإصلاحات
- ربط فهرس `asnz.pdf` باسم «أسباب النزول — الواحدي» بدل الاسم الخاطئ السابق.
- إزالة صياغات توحي بعدم وجود سبب نزول لمجرد عدم وجود بطاقة محلية. الآن البطاقة توضح أن المرجع هو كتاب الواحدي ويمكن فتحه مباشرة.
- إضافة زر عرض كل الكتب والتلاوات وحساب الحجم الإجمالي المتاح، مع تنزيل اختياري.
- إضافة fallback مباشر لملفات GitHub Release بالاعتماد على اسم الـasset عندما لا تنجح مطابقة الـAPI.
- إصلاح دراسة الآية: بطاقة الدراسة تنتقل بعد الآية نفسها وتحافظ على موضع الآية بدل القفز لموضع بعيد.
- إعادة تصميم خطة الحفظ لتوضيح: إجمالي الهدف، وحدة الهدف، عدد الأيام، مقدار الجديد يوميًا، والمحصلة اليومية بصياغة مفهومة.
- إخفاء بطاقة الخطة القديمة المكررة التي كانت تسبب لبسًا.
