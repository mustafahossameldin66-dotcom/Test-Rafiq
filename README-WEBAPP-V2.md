# Rafiq WebApp / PWA V2

هذه النسخة هي مسار الويب الأساسي لرفيق: Website + Installable PWA.

## المحتوى
- 39 عنصر محتوى في الفهرس الحالي: كتب + 3 حزم تلاوات.
- المحتوى يُفتح أو يُنزّل من GitHub Release `content-v1`.
- أسباب النزول المعتمد: **أسباب النزول — الواحدي** (`asnz.pdf`).
- عدم وجود رواية في الفهرسة المحلية لا يعني نفي وجودها؛ زر الكتاب يفتح المصدر مباشرة.

## التشغيل المحلي
```powershell
python -m http.server 8787
```
ثم افتح:
`http://127.0.0.1:8787`

## PWA
- `manifest.webmanifest`
- `sw.js`
- icons 192/512
- يمكن تثبيته على Android/Windows/macOS/Linux من المتصفح الذي يدعم تثبيت PWA.

## ملاحظة عن التلاوات
واجهة التلاوة تدعم الحصري والمنشاوي وفارس عباد عبر الصوت المباشر، وتعرض حزم التنزيل من إصدار المحتوى عند توفرها.
