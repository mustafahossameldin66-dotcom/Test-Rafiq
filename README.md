# Rafiq WebApp / PWA — V7

هذه النسخة تعالج ثلاثة مسارات مباشرة:

1. المصحف: تحميل السورة عند الطلب، وفتح دراسة الآية فورًا قبل انتظار الشبكة، مع ربط ثابت بالسورة والآية.
2. أسباب النزول: المصدر هو **أسباب النزول — الواحدي**، ولا يُفهم غياب بطاقة محلية على أنه نفي لسبب النزول.
3. التلاوات: الحصري والمنشاوي وفارس عباد متاحون تشغيلًا آية بآية عبر EveryAyah، مع روابط الحزم الكاملة.

## المحتوى العلمي

الكتالوج المدمج يعرض الكتب التي رفعها المستخدم ويعطي مسارين: رابط الملف المفرد إن كان منشورًا في GitHub Releases، وحزمة المصدر الأصلية. توجد نسخة `content-packs` منفصلة تضم الأرشيفات الأصلية التي رفعها المستخدم، حتى لا يصبح ملف الموقع الأساسي ~631 MB.

## التشغيل

```powershell
python -m http.server 8787
```

ثم افتح `http://127.0.0.1:8787`.
