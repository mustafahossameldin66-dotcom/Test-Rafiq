# رفيق القرآن — زاد الحافظ

هذه النسخة مبنية على فصل الواجهة عن محرك التطبيق ومصادر المحتوى.

## البنية
- `index.html` — الهيكل فقط.
- `app.css` — الهوية والتصميم.
- `app.js` — منسق التطبيق وواجهة محتوى زاد الحافظ.
- `ui-engine.js` — طبقة العرض والتفاعلات القديمة المعزولة داخل نطاق خاص.
- `storage.js` — IndexedDB للحالة والمحتوى والمصحف وبيانات الحفظ.
- `prayer.js` — حساب مواقيت الصلاة محليًا دون API خارجي.
- `hifz-engine.js` — فصل الحفظ الجديد والتثبيت عن المراجعة المتباعدة.
- `content-manager.js` — حزم المحتوى، التخزين المؤقت، والتنزيل المباشر من Releases.
- `data.js` — البيانات الأساسية التي يحتاجها الإقلاع الفوري.
- `deep-content.json` — المحتوى الموسوعي الموسع، يُحمّل عند فتح الباب فقط.
- `deep-loader.js` — تحميل المحتوى الموسوعي عند الطلب وتخزينه محليًا.

## التوافق مع GitHub Pages
ارفع الملفات الموجودة في الجذر كما هي. لا تغيّر بنية المجلدات.

## المحتوى الكبير
الكتب والتلاوات الكبيرة تأتي من GitHub Release `content-v1`. التطبيق لا يعتمد على صفحة Assets للمستخدم؛ يستخدم رابط الـAsset المباشر عند توفره.

## ملاحظة المصحف
التطبيق يدعم تخزين نص المصحف في IndexedDB بعد الحصول عليه من ملف محلي أو من حزمة المحتوى إذا كان `quran-uthmani.json` موجودًا في الـRelease.
