# Rafiq Zad — Real Content Pack

هذه النسخة تحتوي ملفات PDF الفعلية التي كانت مرفوعة مع المشروع، وتستخدم روابط GitHub Releases المباشرة لبقية الأصول المنشورة، وتستخدم EveryAyah لتشغيل الآيات بصوت الحصري والمنشاوي وفارس عباد.

- الكتب المحلية: `content/zad/**`
- manifest: `content/zad/catalog.json`
- بقية أصول الإصدار: `content-manifest.json` + GitHub Release `content-v1`
- أسباب النزول: PDF الواحدي محلي + عرض نصي حسب السورة/الآية عبر Quranpedia
